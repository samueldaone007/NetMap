How it behaves

  1. 01
    Headers are not trusted.

    You map every column yourself. Any column can feed any field.

  2. 02
    Cleanup is conservative.

    NIL, n/a and blanks become empty. Dates or serial numbers in text columns are flagged, not guessed.

  3. 03
    Ranges expand before save.

    LAN2-7, 19,20 and 4,5,7-12 become individual ports in the preview.

  4. 04
    Unknown does not fail.

    Free-text references create flagged placeholder devices and ports for a later walk.

  5. 05
    One batch, one undo.

    Commit an import once, then roll the whole batch back if it was a bad idea.
